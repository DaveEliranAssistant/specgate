TRUST & TROUBLESHOOTING

Know the boundary.

Does SpecGate run or upload my service?

The scanner reads committed Git blobs and parses source; it does not import service modules, run project scripts or start the service. The local scan makes no model/network calls. This walkthrough has no upload endpoint and no third-party assets or analytics. The optional waitlist is the only form that sends data to a server, and only after you consent. Installation and CI artifact access are separate trust steps.

Why did my edit not appear?

Uncommitted and untracked files are excluded. Check the pinned commit in the report and your explicit source scope. Do not commit credentials or confidential changes just to make a scan pass.

What does unsupported mean?

The tool cannot resolve a construct with this adapter. Treat incomplete coverage as review required, not PASS. Do not hide the gap or regenerate an accepted baseline to silence it.

What can I safely share?

Route paths, identifiers, file names and hashes can still be confidential. Review reports before sharing, keep raw reports private and use minimal redacted examples. This is not a complete secret scanner.

How do I stop or roll back a pilot?

Remove the consuming CI step or pin the previous accepted archive. Keep reviewed expectations intact. Enabling enforcement, releasing software or changing repository protections requires separate owner approval.
